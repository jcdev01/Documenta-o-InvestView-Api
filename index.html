Investview-API

API REST para gestão e simulação de investimentos, controle de favoritos, carteiras de usuários e análise de correlação entre ativos por meio de um Grafo Global de Coocorrência.

Autenticação dupla

A API aceita dois tipos de token no mesmo header Authorization: Bearer <TOKEN>.

Forma 1 · Login com Google (OAuth2 Resource Server)

Front + Google Identity Services
→
ID Token (JWT)
→
Bearer na API
→
Validação JWK + audience
→
Provisionamento JIT
  1. O frontend autentica o usuário com o Client ID e recebe o ID Token com as claims email, email_verified: true, name e sub.
  2. O backend valida a assinatura no JWK Set URI oficial do Google e a audience (APP_OAUTH_GOOGLE_CLIENT_ID).
  3. Provisionamento JIT: na primeira chamada cria o usuário em tb_users (senha nula, role USER). Se o e-mail estiver em APP_SECURITY_ADMIN_EMAILS, atribui ADMIN.

Forma 2 · Login local (e-mail e senha) com Access + Refresh

Access Token

JWT HMAC-SHA256 · TTL 1 h
Claims: iss/aud: investview-api, email, role, name

Refresh Token

Token opaco aleatório de 32 bytes · TTL 7 dias · armazenado no Redis

Rotação atômica

POST /auth/refresh invalida o refresh anterior e emite um novo par. Reuso do antigo retorna 401.

Logout seguro

POST /auth/logout revoga a chave no Redis e retorna 204.

Controle de acesso (RBAC + IDOR)

RegraDetalhe
RolesUSER (padrão) e ADMIN
Proteção IDOR requireOwnerOrAdminRotas /users/{userId}/... exigem userId igual ao ID do usuário autenticado. Tentar acessar outro usuário retorna 403. ADMIN acessa qualquer ID.
Gestão de usuários/users/** é exclusivo do perfil ADMIN.

Guia de implementação no frontend

1 · Interceptor Axios com refresh automático

Ao receber 401, o interceptor chama /auth/refresh uma única vez (mesmo com várias requisições simultâneas), repete as requisições pendentes e, se o refresh falhar, desloga o usuário.

import axios from 'axios';

const api = axios.create({ baseURL: import.meta.env.VITE_API_URL });

const store = {
  get access()  { return localStorage.getItem('accessToken'); },
  get refresh() { return localStorage.getItem('refreshToken'); },
  save(t) {
    localStorage.setItem('accessToken', t.token);
    localStorage.setItem('refreshToken', t.refreshToken);
  },
  clear() { localStorage.removeItem('accessToken'); localStorage.removeItem('refreshToken'); }
};

api.interceptors.request.use(function (config) {
  if (store.access) config.headers.Authorization = 'Bearer ' + store.access;
  return config;
});

let refreshing = null; // promise compartilhada: evita refresh em paralelo

function doRefresh() {
  if (!refreshing) {
    // axios "puro" para não cair no próprio interceptor
    refreshing = axios
      .post(api.defaults.baseURL + '/auth/refresh', { refreshToken: store.refresh })
      .then(function (res) { store.save(res.data); return res.data.token; })
      .finally(function () { refreshing = null; });
  }
  return refreshing;
}

api.interceptors.response.use(
  function (res) { return res; },
  async function (error) {
    const original = error.config;
    const isAuthRoute = original.url.startsWith('/auth/');
    if (error.response?.status === 401 && !original._retry && !isAuthRoute && store.refresh) {
      original._retry = true;
      try {
        const newToken = await doRefresh();
        original.headers.Authorization = 'Bearer ' + newToken;
        return api(original);
      } catch (e) {
        store.clear();
        window.location.href = '/login';
      }
    }
    return Promise.reject(error);
  }
);

export default api;
Atenção: o refresh token é rotacionado a cada uso. Sempre salve o par novo devolvido por /auth/refresh, pois reutilizar o antigo retorna 401. Para o login Google, o ID Token expira em cerca de 1 h e não passa por esse fluxo: renove-o pelo Google Identity Services.

2 · Cotações em tempo real com a brapi

O fluxo é: buscar os symbol nesta API, juntar em uma única chamada à brapi e mesclar o resultado por símbolo.

const BRAPI = 'https://brapi.dev/api/quote';
const BRAPI_TOKEN = import.meta.env.VITE_BRAPI_TOKEN; // crie em brapi.dev

export async function fetchQuotes(symbols) {
  if (!symbols.length) return {};
  const url = BRAPI + '/' + symbols.join(',') + '?token=' + BRAPI_TOKEN;
  const res = await fetch(url);
  if (!res.ok) throw new Error('brapi: ' + res.status);
  const data = await res.json();
  const bySymbol = {};
  data.results.forEach(function (q) {
    bySymbol[q.symbol] = {
      price: q.regularMarketPrice,
      changePct: q.regularMarketChangePercent,
      name: q.shortName
    };
  });
  return bySymbol;
}

// Favoritos com cotação
export async function favoritesWithQuotes(userId) {
  const favs = (await api.get('/users/' + userId + '/favorites')).data;
  const quotes = await fetchQuotes(favs.map(function (f) { return f.symbol; }));
  return favs.map(function (f) { return Object.assign({}, f, quotes[f.symbol] || {}); });
}
import { useEffect, useState } from 'react';

export function usePortfolioValue(userId) {
  const [state, setState] = useState({ items: [], total: 0, loading: true });

  useEffect(function () {
    let alive = true;
    async function load() {
      const pf = (await api.get('/users/' + userId + '/portfolio')).data;
      const quotes = await fetchQuotes(pf.items.map(function (i) { return i.symbol; }));
      const items = pf.items.map(function (i) {
        const price = quotes[i.symbol]?.price ?? 0;
        return Object.assign({}, i, { price: price, value: price * i.quantity });
      });
      const total = items.reduce(function (s, i) { return s + i.value; }, 0);
      if (alive) setState({ items: items, total: total, loading: false });
    }
    load();
    const id = setInterval(load, 60000); // atualiza a cada 1 min
    return function () { alive = false; clearInterval(id); };
  }, [userId]);

  return state;
}
Dica: o plano gratuito da brapi tem limites de requisições e de ativos por chamada. Faça cache em memória por 30 a 60 s e agrupe todos os símbolos em uma só requisição. Valor total da carteira = quantity × price, calculado no front.

3 · Sugestões de UI/UX

Login dual

Botão "Entrar com Google" no topo, divisor "ou" e formulário e-mail/senha. Mostre erro inline em 401 sem revelar qual campo falhou. Salve o par de tokens apenas no login local.

Dashboard de favoritos

Grade de cards com símbolo, nome, preço e variação colorida (verde/vermelho). Estrela para favoritar/desfavoritar, busca com autocomplete da brapi e estado vazio com chamada para ação. Trate 409 como "já está nos favoritos".

Carteira consolidada

Cabeçalho com patrimônio total e variação do dia, tabela ordenável (ativo, quantidade, preço, valor, % da carteira) e gráfico de rosca de alocação. Edição inline de quantidade (PUT) e botão "adicionar cotas" (POST soma).

Visualizador de grafo

Cytoscape.js ou Vis.js com GET /graph. Tamanho do nó = grau, espessura da aresta = weight. Clique no nó para listar /neighbors; dois nós selecionados disparam /path e destacam o caminho. Cores por componente conexo.

Cuidado no POST de itens da carteira: ele faz upsert somatório. Se o usuário "corrige" a quantidade, use PUT /portfolio/items/{itemId} (valor absoluto). Caso contrário a quantidade será duplicada.
